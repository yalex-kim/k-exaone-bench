K-EXAONE 2.5 · reasoning_effort 비교

LG AI연구원 EXAONE API의 k-exaone_v2.5에 같은 과제를 max / high / low로 한 번씩 시켜본 결과입니다. 과제당 1회 실행이라 통계가 아니라 인상 비교용입니다. (2026-11-10)

📊 평가표

기준별 1~5점 (5 = 매우 좋음). 결과물과 코드를 직접 확인해 매긴 주관적 점수입니다. 결과가 없으면 0점.

⏱️ 생성 시간

요청부터 응답 완료까지 걸린 실제 시간 (스트리밍). 막대 안 회색은 추론 토큰 비율.

🚲 자전거 타는 펠리컨 (SVG)

프롬프트: Generate an SVG of a pelican riding a bicycle

🏡 풍차 3D (Three.js)

프롬프트: index.html 하나로 Three.js 3D 장면 — 언덕 위 풍차, 회전하는 날개 4장, 나무 5그루, 그림자, OrbitControls … (전문) · 카드를 눌러 실제 장면을 실행할 수 있어요. 드래그로 회전.

정리

  • 느림 — 가장 빨라도 10분, 대부분 20~30분. 출력의 83~93%가 추론 토큰이고 속도는 약 25 토큰/초.
  • effort를 낮춰도 추론량이 크게 줄지 않음 — low도 추론 토큰 2~4만 개. 오히려 low 결과가 가장 나았음.
  • 꼼꼼하지만 마무리가 약함 — 3D 결과 3개 중 2개가 import 누락, 캔버스 미연결 같은 기본 실수로 빈 화면.
  • SVG 그림은 준수 — 펠리컨이 자전거에 제대로 올라탄 그림을 두 번 모두 그림.
  • API 운영 — 비스트리밍은 600초, 스트리밍은 약 30분에 끊김. 초당 1회 요청 제한.
